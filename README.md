# PhoneBook
## A simple CLI phonenumber manager with C

[How It Works]

  The PhoneBook program uses structs to track phone numbers, and stores them into an array of similer structs. 
  This allows the program to easily allocate, edit, and remove phone numbers to the users liking.

[Useage]

to use this program, simply run the executable in your terminal.
If you don't have a compiler for C, you need one to run this program.
On linux, you can use the command:
sudo apt install gcc
